# 부력 탐험

태블릿을 자동차 핸들처럼 돌려 물과 중력의 방향을 바꾸고, 잠수정 탱크의 물을 조절해 탈출하는 과학 게임입니다. **360° 조작, 연속적인 입자 물, 11개 미로, 밀도가 다른 액체, 전체 화면**을 지원합니다.

**[게임 열기](https://ryowoo2726-hue.github.io/buoyancy_game/)**

## 실행과 개발

Node.js 22.12 이상이 필요합니다. 검증 환경은 Node 24입니다.

```sh
npm ci
npm run dev
```

표시되는 주소를 브라우저에서 엽니다. 기본 주소는 `http://localhost:5173/`입니다.

Google Drive 가상 드라이브에서 npm 설치가 `EBADF`나 `EPERM`으로 실패하면 **`개발실행.cmd`**를 실행하세요. 원본 소스를 `%LOCALAPPDATA%/CodexProjects`의 프로젝트 전용 폴더에 복사해 실행합니다. 원본 편집 후 다시 실행하면 수정 내용이 복사됩니다. 사용 중인 포트는 피해서 실행합니다.

```sh
npm test
npm run build
npm run preview
```

완성된 `dist`가 있으면 **`미리보기.cmd`**로 설치 없이 미리 볼 수도 있습니다. 기본 주소는 `http://localhost:4173/`입니다. `dist/index.html`은 HTTP 서버로 실행합니다. GitHub에는 소스만 올리며 `dist`, `node_modules`, ZIP은 제외합니다.

## 조작

| 기능 | 터치·마우스 | 키보드 |
| --- | --- | --- |
| 360° 기울기 | 센서 또는 −180°~+180° 슬라이더 | ← → 계속 누르기 |
| 탱크 물 빼기 | 왼쪽 아래 버튼 길게 누르기 | W |
| 탱크 물 채우기 | 오른쪽 아래 버튼 길게 누르기 | S |
| 정지·계속 | 위쪽 정지 버튼 | 스페이스 |
| 0° 보정 | 과녁 버튼 | 버튼에 포커스 후 Enter |
| 단계 선택 | 위쪽 단계 목록 | 목록에 포커스 후 방향키 |
| 전체화면 | 네 모서리 모양 버튼 | 버튼에 포커스 후 Enter |

각도 표시는 0°~359°입니다. 중력은 0°에서 아래, 90°에서 오른쪽, 180°에서 위, 270°에서 왼쪽을 향합니다. 슬라이더의 양 끝은 같은 방향이며 각도 경계를 건너갈 때 짧은 방향으로 이어집니다. 센서와 키보드는 여러 바퀴 연속 회전할 수 있습니다.

태블릿은 **화면을 정면으로 바라보며 세워 잡고** 센서로 시작하세요. 첫 유효한 자세를 기준으로 잡습니다. 화면이 거의 수평이면 화면 안쪽 중력의 방향을 구분하기 어려워 마지막 유효한 자세를 유지합니다. 과녁 버튼으로 현재 자세를 다시 0°로 잡을 수 있습니다. HTTPS와 기기별 센서 권한이 필요하며 거절·무응답·연결 중단에서는 수동 조작으로 전환합니다.

전체화면을 지원하면 시작할 때 요청하고, 가능한 브라우저에서는 가로 방향을 유지합니다. 지원되지 않아도 브라우저 표시 영역을 가득 채웁니다. 센서 모드에서는 슬라이더를 숨깁니다. 화면 크기를 바꿔도 물리 좌표와 미로 비율은 유지됩니다.

탱크 버튼은 잠수정 내부에만 작용합니다. 비움부터 가득까지 약 3.85초 걸립니다. 손을 떼거나 터치를 취소하거나 포커스를 잃으면 즉시 멈춥니다. 두 버튼을 함께 누르면 상쇄합니다. 다른 탭으로 이동하면 일시 정지됩니다.

출구에 닿으면 완료 시간과 다음 단계 버튼을 표시합니다. 마지막 단계 이후에는 처음부터 다시 시작할 수 있습니다. 단계 목록에서 모든 미로를 바로 선택할 수 있으며 재시작은 현재 단계의 물·잠수정·시간을 초기화합니다.

## 11개 단계

기존 미로에 10개를 추가했습니다. 통로 수, 통로 폭, 중간 높이의 문, 추가 벽과 밀도 차이를 조합해 난이도를 올립니다.

| 단계 | 이름 | 주요 변화 |
| --- | --- | --- |
| 1 | 첫 번째 잠수 | 기본 3개 통로 |
| 2 | 이어지는 물길 | 위아래 통로 폭 168px |
| 3 | 네 번의 잠수 | 통로 4개, 폭 156px |
| 4 | 중간 높이의 문 | 중간 문과 추가 벽, 폭 144px |
| 5 | 진한 물의 방 | 고밀도 액체 1.18, 폭 132px |
| 6 | 가벼운 물과 무거운 물 | 0.85와 1.18, 통로 5개 |
| 7 | 뒤집힌 물길 | 중간 문, 폭 108px |
| 8 | 여섯 개의 수문 | 통로 6개, 0.82와 1.22 |
| 9 | 좁아지는 창 | 엇갈린 중간 문, 폭 96px |
| 10 | 밀도의 미로 | 폭 84px, 0.78과 1.25 |
| 11 | 마지막 심해 | 통로 7개, 폭 72px, 0.74와 1.28 |

밀도 구역은 초기 액체의 성질을 정합니다. 액체가 흐르면 그 밀도와 색도 함께 움직이고 경계에서 섞입니다. 고밀도 액체는 보라색, 저밀도 액체는 금색을 띱니다. 화면 위 ‘물’ 값은 잠수정 주변에 잠긴 액체의 평균 밀도이며 물 밖에서는 `—`를 표시합니다. 값은 게임의 상대 밀도입니다.

## 물과 부력 구현

`core/water.ts`는 입자의 위치·속도·액체 밀도를 저장합니다. 중력으로 이동한 후 밀도 제약을 4회 반복해서 지나친 압축을 줄이고, 약한 응집과 점성으로 입자 뭉침과 분산을 억제합니다. 관성을 유지하므로 기울기를 바꿔도 흐름이 즉시 반전하지 않습니다. 밀도 제약은 [Position Based Fluids 연구](https://matthias-research.github.io/pages/publications/pbf_sig_preprint.pdf)를 참고했습니다.

벽의 고정 경계 샘플과 충돌 처리를 사용하며 물 입자가 벽이나 화면 밖으로 빠져나가지 않도록 합니다. 닫힌 방은 다른 방과 물을 교환하지 않습니다. 입자 수·입자 체적 합·액체 물질의 질량을 유지합니다. 12px 격자는 벽 판정과 관측에 사용하며 물을 칸별 사각형으로 그리지 않습니다.

`render/surface.ts`는 부드러운 입자 밀도장에서 연속적인 등밀도 수면을 추출합니다. Canvas의 벡터 경로를 사용하고 내부 영역을 합쳐 격자 테두리를 표시하지 않습니다. 직전·현재 입자 위치를 프레임 시간에 맞춰 보간합니다. 벽을 가로지르는 밀도장 기여를 차단하고 그림도 실제 통로 영역으로 잘라냅니다. 입자와 계산 배열, 렌더링 버퍼를 재사용합니다.

잠수정과 물은 60Hz 고정 간격으로 계산합니다. 탱크의 상대 밀도는 0%에서 0.65, 50%에서 1.00, 100%에서 1.35입니다. 잠수정 외부 부피는 고정이고 탱크에 따라 질량만 변합니다. 부력은 각 침수 샘플의 액체 밀도를 반영해 중력 반대 방향으로 적용합니다. 저항은 물의 속도에 대한 상대 운동에 적용하므로 중성 부력의 잠수정도 흐름을 따라 이동합니다.

수면과 압력은 경량 게임용 수치 근사입니다. 입자 체적 합은 보존하지만 그려지는 체적에는 근사 오차가 있습니다. 잠수정이 액체를 밀어내는 양방향 상호작용은 후속 확장 범위입니다.

360° 센서는 화면 안쪽 중력 벡터의 두 성분으로 각도를 구하며, 회전 경계와 화면 방향 변경을 이어서 처리합니다. 좌표계와 권한은 [W3C Device Orientation and Motion 표준](https://www.w3.org/TR/orientation-event/)을 참고했습니다.

## 파일 구조

```text
src/core/water.ts        입자 액체, 벽, 밀도 이동, 침수 샘플링
src/core/submarine.ts    Matter.js, 탱크 질량, 부력, 흐름과 저항
src/input/              360° 센서와 터치·마우스·키보드
src/game/game.ts        단계 전환, 고정 시간 루프, 완료와 정지
src/render/             연속 수면, 미로와 잠수정 렌더링
src/ui/view.ts          게임 안의 조작과 단계 선택
src/stages/*.json       11개 미로와 초기 액체 밀도 구역
src/stages/index.ts     단계 순서
tests/                  액체·밀도·센서·입력·단계·탈출 검사
.github/workflows/      자동 검사와 Pages 배포
```

스테이지의 미로·벽 좌표는 `cellSize`의 배수입니다. `densityZones`는 초기 액체 영역의 사각형과 밀도, 이름을 정의합니다. 새 JSON을 `stages/index.ts`에 추가하면 단계 선택과 다음 단계 기능에 반영됩니다.

## 검사

자동 검사 **59개**가 통과했습니다. 주요 범위는 다음과 같습니다.

- 0°·90°·180°·270°에서 액체 이동, 급격한 방향 변경과 관성
- 초기 물 체적, 입자 수, 액체 물질 질량 보존과 벽 충돌
- 정착한 액체 내부의 빈틈과 셀 경계에서의 연속성
- 닫힌 방의 입자·그림 격리와 열린 통로의 이동
- 서로 다른 액체 밀도의 이동·혼합, 잠수정 부력과 물의 흐름에 따른 이동
- 실제 물리 객체를 기울기와 탱크 입력만으로 조작해 첫 미로 탈출
- 11개 미로 각각의 잠수정 크기와 여유를 반영한 경로, 단계 선택·전환·마지막 완료
- 센서 권한 거부·무응답, 두 바퀴 연속 회전, 평평한 자세와 각도 경계
- 터치 해제·취소·동시 입력, 정지·재시작, 전체화면 요청 거절

센서는 모의 이벤트로 검사했고 계산된 수면 이미지를 확인했습니다. 실제 태블릿의 센서와 프레임 속도는 실기기 확인이 필요합니다. HTTPS에서 가로 모드로 시작해 한 바퀴 돌리며 위쪽으로도 물이 이동하는지, 과녁 보정·각도 경계·기기 화면 회전이 자연스러운지 확인하세요. 이후 밀도 구역, 좁은 통로와 버튼 밖에서 손 떼기를 점검하세요.

## GitHub Pages

저장소 **Settings → Pages → Source**는 **GitHub Actions**로 설정합니다. `main`에 푸시하면 설치·검사·Vite 빌드 후 `dist`를 배포합니다. Actions에서 배포 workflow를 수동 실행할 수도 있습니다.

`main / (root)`의 원본 소스를 직접 배포하면 개발용 TypeScript 경로를 읽지 못해 빈 화면이 됩니다. Pages에는 빌드된 `dist`가 배포되어야 합니다. Vite의 `base: './'`로 저장소 하위 주소에서 자산을 상대 경로로 불러옵니다. 외부 API 키나 백엔드가 필요하지 않습니다.
