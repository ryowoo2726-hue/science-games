# 🎯 탄성 퀘스트 (Elasticity Physics Puzzle Game)

중학교 1학년 과학 5단원 **여러 가지 힘 - '탄성력'** 탐구용 20단계 인터랙티브 물리 퍼즐 웹 게임입니다.

---

## 📖 게임 소개
- **훅의 법칙 ($F = kx$)**: 용수철을 당긴 변형 길이($x$)와 용수철 재료의 탄성계수($k$)에 비례하여 탄성력($F$)이 결정됩니다.
- **탄성 충돌과 반사**: 벽과 범퍼에 부딪힐 때 입사각과 반사각의 원리에 따라 통통 튕기며 목적지(골대)에 도달해야 합니다.
- **20개 고난도 미로 스테이지**: 단순 일직선 통과가 불가능하도록 정면이 차단되어 있으며, 1~4단 연속 반사, 슈퍼 범퍼, 스펀지 함정, 스위치 게이트, 움직이는 패들 등 다양한 물리 기믹을 공략해야 합니다.

---

## 🛠 주요 기능
1. **태블릿 친화적 반응형 UI**: 학교 태블릿(아이패드, 갤럭시탭, 크롬북) 가로 화면에 최적화된 고대비 다크 랩(Lab) 테마.
2. **3가지 용수철 재료 선택**:
   - 부드러운 고무 ($k = 1.0$)
   - 표준 강철 ($k = 1.8$)
   - 슈퍼 티타늄 합금 ($k = 2.8$)
3. **무설치 단일 웹 앱**: 별도의 프로그램 설치 없이 `index.html`을 브라우저로 열면 즉시 실행되며, Web Audio API를 활용한 자체 사운드 신디사이저가 내장되어 있습니다.

---

## 🚀 실행 방법
`index.html` 파일을 브라우저(Chrome, Whale, Edge, Safari 등)에서 더블 클릭하여 실행합니다.
