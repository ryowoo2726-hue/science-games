# 부력 탐험 · 작은 잠수정의 부력 미로

태블릿을 기울여 중력과 물의 흐름을 바꾸고, 잠수정 내부 탱크의 물을 조절해 탈출하는 한국어 과학 게임입니다. 첫 번째 미로, 화면 안의 터치/키보드 조작, 센서 보정, 완료 시간, 재시작을 포함합니다. 설명 사이드바와 힘 화살표를 제거하고 게임이 브라우저 화면을 채우도록 구성했습니다.

**[웹게임 바로 열기](https://ryowoo2726-hue.github.io/buoyancy_game/)**

## 바로 실행

제공된 프로젝트 ZIP에는 완성된 `dist`가 포함되어 있습니다. Windows에서 **`미리보기.cmd`를 두 번 클릭**하고 표시된 주소(기본 `http://localhost:4173/`)를 브라우저에서 엽니다. 이미 만들어 둔 `dist`를 사용하므로 npm 설치가 필요하지 않습니다. Node.js 22.12 이상이 필요합니다. 종료할 때 실행 창에서 `Ctrl+C`를 누르세요. `dist/index.html`을 직접 더블클릭하는 방식 대신 HTTP 서버로 실행해야 합니다.

GitHub 저장소를 복제한 경우에는 소스만 내려받으므로 먼저 `npm ci`와 `npm run build`로 `dist`를 생성하세요. `node_modules`, `dist`, ZIP은 저장소에 올리지 않습니다.

학생들은 위 HTTPS 링크로 설치 없이 접속할 수 있습니다. GitHub Pages는 빌드된 `dist`를 GitHub Actions로 배포하며, `main`에 푸시하면 자동으로 갱신됩니다.

## 개발 실행

Node.js 22.12 이상(검증 환경: Node 24.18), npm이 필요합니다.

```sh
npm ci
npm run dev
```

브라우저에서 `http://localhost:5173/`에 접속합니다. `npm install`도 가능하지만, 재현 가능한 설치에는 포함된 `package-lock.json`과 `npm ci`를 권장합니다.

현재와 같은 Google Drive 가상 드라이브에서 npm 설치가 `EBADF`, `EPERM`, 파일 쓰기 오류로 실패하면 **`개발실행.cmd`**를 사용하세요. 소스만 `%LOCALAPPDATA%/CodexProjects/부력 미로 전용 폴더`에 복사하여 설치하고 Vite를 실행합니다. 원본 파일은 원래 폴더에 유지됩니다. 원본을 편집한 뒤 이 실행 파일을 다시 실행하면 수정 내용이 복사됩니다. 5173 포트가 사용 중이면 다음 빈 포트로 실행되므로 창에 표시된 주소를 사용하세요. 또는 전체 프로젝트를 `C:/Projects/buoyancy-maze` 같은 로컬 폴더에 복사한 뒤 위 명령을 실행할 수 있습니다.

## 조작

| 조작 | 태블릿/마우스 | 키보드 |
| --- | --- | --- |
| 기울기 | 센서 또는 −90°~+90° 슬라이더 | ← → 길게 누르기 |
| 탱크 물 빼기 | ‘물 빼기’ 버튼 길게 누르기 | W 길게 누르기 |
| 탱크 물 채우기 | ‘물 채우기’ 버튼 길게 누르기 | S 길게 누르기 |
| 일시 정지/계속 | 화면 위 정지 버튼 | 스페이스 |
| 기준 각도 | 화면 위 과녁 모양 버튼 | 버튼에 포커스 후 Enter |
| 전체화면 | 화면 위 네 모서리 모양 버튼 | 버튼에 포커스 후 Enter |

각도 0°의 중력은 아래쪽, +90°는 오른쪽, −90°는 왼쪽입니다. 화면 하단의 두 버튼은 잠수정 내부 탱크에만 작용합니다. 탱크는 약 3.85초 동안 길게 누르면 비움에서 가득으로 변합니다. 두 버튼을 동시에 누르면 서로 상쇄하며, 손을 떼거나 터치가 취소되거나 창 포커스가 사라지면 즉시 정지합니다. 탭을 다른 곳으로 전환하면 게임이 일시 정지됩니다.

시작할 때 지원되는 브라우저에서는 전체화면을 요청합니다. 전체화면 API가 없거나 요청이 거절돼도 게임은 브라우저의 표시 영역을 가득 채웁니다. 미로 비율과 물리 좌표를 유지하며, 화면 비율에 따라 여백이 생길 수 있습니다. 센서가 연결되면 수동 각도 슬라이더는 숨겨지고, ‘수동 조작’을 누르면 다시 표시됩니다. 재시작은 초기 탱크·물·위치로 되돌려 즉시 새 라운드를 시작합니다.

센서 시작 버튼을 누르면 필요한 기기에서 권한을 요청합니다. 첫 유효한 측정값을 기준 자세로 잡습니다. 화면 방향이 바뀌면 다시 보정하며, 작은 흔들림은 무시하고 각도는 부드럽게 적용합니다. 권한 거부, 지원되지 않는 기기, 3초 동안 값이 없는 경우, 연결 중단에서는 수동 조작으로 전환합니다. 처음에는 화면을 위로 둔 편안한 자세에서 시작하고 필요할 때 ‘0° 보정’을 누르세요.

미로는 **아래 통로 → 위 통로 → 아래 통로 → 초록색 출구** 순서입니다. 기울기와 탱크 상태를 함께 바꿔야 합니다. 막히면 잠시 멈추고 물의 높이와 탱크 수위를 살펴보세요. 출구에 잠수정이 닿으면 시간 기록과 완료 화면을 표시합니다.

## 수업에서 관찰할 것

- 외부 부피는 일정하고, 탱크 물이 늘면 질량과 평균 밀도가 증가합니다.
- 상대 밀도는 탱크 0%에서 0.65, 50%에서 1.00, 100%에서 1.35입니다. 물의 상대 밀도는 1.00입니다.
- 중력은 `밀도 × 외부 부피 × g`, 부력은 `물의 밀도 × 잠긴 부피 × g`입니다. 기울여도 두 힘은 반대 방향입니다.
- 완전히 물에 잠긴 잠수정이 물과 같은 평균 밀도이면 중성 부력입니다. 일부만 잠겨 수면에 떠서 힘이 균형인 경우와 구분해 관찰하세요.
- 물 밖에서는 부력이 0입니다. 밀도가 작더라도 물 밖에서는 중력을 받아 내려갑니다.
- 벽에 닿거나 관성이 남아 있으면 중력·부력의 우세와 실제 순간 이동 방향이 다를 수 있습니다.

화면의 중력 가속도는 게임 속도에 맞춰 조정했지만, 질량·부피·잠긴 비율에 따른 두 힘의 관계는 동일하게 계산합니다. 화면에는 간단한 기울기·밀도·탱크 수위만 표시합니다.

## 물 시뮬레이션

`src/core/water.ts`는 12px 격자의 보존형 셀 모델입니다. 각 셀에 물의 양을 저장하고, 벽이 없는 상하좌우 공유 면으로만 물을 교환합니다. 교환량은 한 셀에서 뺀 만큼 이웃 셀에 더합니다. 닫힌 공간 사이에 경로가 없으면 물을 교환할 수 없습니다. 기울일 때 전역에서 물을 다시 채우거나 파란 사각형을 회전시키는 처리는 없습니다.

젖은 셀과 인접한 자유 표면에 대해 중력 성분을 포함한 암시적 압력 방정식을 24회 반복해 풉니다. 긴 수중 통로의 압력 전달이 느렸던 두 셀 단위 평형 교환을 대체했습니다. 압력은 벽이나 마른 통로를 가로질러 전달하지 않으며, 실제 물 이동은 여전히 인접한 열린 면에서만 일어납니다. 면당 이동량을 제한하고 한 셀의 모든 유출량을 함께 제한해, 급격한 기울기에서도 음수 수량과 순간 재배치를 방지합니다. 계산 배열은 재사용합니다.

잠수정과 물을 모두 60Hz의 고정 간격으로 계산합니다. 렌더링은 직전·현재 물 상태를 시간에 맞춰 보간하고 수면 가장자리를 부드럽게 표현합니다. 시각적 가장자리 처리는 벽 바깥으로 번지지 않도록 잘라냅니다. Canvas 필터를 지원하지 않는 브라우저에서도 시간 보간은 적용합니다. 초기에는 미로 빈 셀 부피의 정확히 50%를 정지 수면으로 설정합니다. 센서 계산·보정·필터는 기존 구현을 유지했습니다.

첫 버전의 근사 범위도 있습니다. 깊은 물에서 압력을 전달하기 위해 셀당 작은 수치적 압축률(0.002)을 허용합니다. 따라서 셀의 질량은 1을 약간 넘을 수 있으며 화면은 가득 찬 셀로 표시합니다. 자유 표면은 격자 해상도 안에서 중력에 수직인 선으로 근사하며, 특히 큰 각도로 급격히 바꾸면 전체 수면이 안정되기까지 시간이 걸립니다. 수면 부근의 부분 채움 형태와 잠긴 비율 샘플링에는 같은 중력 방향을 사용합니다.

Navier–Stokes 기반 유체 해석, 파도·난류, 잠수정에 의한 물의 체적 밀어내기와 압력 되먹임은 구현하지 않았습니다. 물은 잠수정의 침수율과 부력에 영향을 주는 경량 모델입니다. 내부 탱크는 별도 저장소로 이상화했으므로 탱크 버튼으로 외부 물의 양이 변하지 않습니다. 수업용 개념 탐구를 위한 첫 프로토타입이며 실험 측정용 시뮬레이터는 아닙니다.

### 실제 태블릿 점검

1. Android Chrome 및 iPad Safari에서 배포한 HTTPS 주소를 열고 가로 모드로 둡니다. LAN의 `http://192.168…` 주소는 수동 조작 점검에 사용하고, 센서는 HTTPS에서 점검합니다.
2. ‘태블릿 센서로 시작’을 누르고 필요한 기기에서 권한을 허용합니다. 연결됨 상태, 기준 0°, 오른쪽을 낮추면 + 각도인지 확인합니다. 화면 회전 방향을 반대로 해도 확인합니다.
3. 0°, −90°, +90°를 유지해 물의 이동 방향과 반응 속도를 봅니다. 급격히 좌우를 바꿔도 벽을 통과하는 물이 없는지 확인합니다. 연결 통로의 폭과 거리에 따라 정착 시간은 달라집니다.
4. 과녁 모양 ‘0° 보정’ 버튼을 누른 후 기준이 0°로 돌아오는지 확인합니다. 권한을 거부한 경우 슬라이더가 활성화되는지도 확인합니다.
5. 탱크를 0%, 50%, 100%로 바꾸며 완전히 물속에 있을 때의 운동을 비교합니다. 잠수정이 수면에 일부만 잠길 때 뜨는 움직임이 달라지는지 확인합니다.
6. 버튼을 누른 채 손가락을 밖으로 이동하고 손을 뗍니다. 탱크 수위가 즉시 멈추는지, 두 버튼을 동시에 누르면 멈추는지 확인합니다.
7. 탭 전환/화면 잠금 뒤 정지 화면이 나타나는지, 계속하기·재시작·탈출 시간과 성공 화면이 정상인지 확인합니다.
8. 태블릿 가로/세로 및 PC의 다양한 창 크기에서 조작 버튼, 글자, 미로가 잘리는지 확인합니다. 전체화면 진입·종료와 물이 흐르는 중의 프레임 속도를 확인합니다.

센서의 HTTPS 및 권한 요구는 [MDN DeviceOrientationEvent](https://developer.mozilla.org/en-US/docs/Web/API/DeviceOrientationEvent)를 참고했습니다.

## GitHub Pages 배포

1. 이 프로젝트를 GitHub 저장소의 `main` 브랜치에 올립니다. 푸시 및 PR에서 자동 검사와 빌드가 실행됩니다. `node_modules`는 업로드하지 않습니다.
2. 저장소 **Settings → Pages → Build and deployment → Source**를 **GitHub Actions**로 선택합니다. `Deploy from a branch`로 원본 `main / (root)`를 배포하면 개발용 HTML의 TypeScript 경로를 불러오지 못해 빈 화면이 됩니다.
3. `main`에 푸시하면 설치 → 검사 → 빌드 → `dist` 배포가 자동 실행됩니다. 직접 다시 배포하려면 Actions의 ‘Deploy buoyancy maze to GitHub Pages’에서 **Run workflow**를 실행합니다.
4. Pages에 표시되는 HTTPS 주소를 학생들에게 링크나 QR 코드로 안내합니다.

Vite의 `base: './'` 설정으로 사용자 홈페이지와 저장소 하위 경로 모두에서 자산을 상대 경로로 불러옵니다. 외부 API 키, CDN 스크립트, 백엔드가 필요하지 않습니다. 웹 폰트도 외부에서 받지 않습니다. 다른 정적 HTTPS 호스팅에서도 `dist`의 내용을 그대로 올릴 수 있습니다.

배포 절차와 workflow는 [Vite 공식 정적 사이트 배포 안내](https://vite.dev/guide/static-deploy)를 참고했습니다. 충돌과 힘의 적용은 [Matter.js Body API](https://brm.io/matter-js/docs/classes/Body.html)를 사용합니다.
