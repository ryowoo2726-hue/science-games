# 🌌 중력 골프 (Gravity Golf)

> **중학교 1학년 과학 5단원 (힘과 운동 - 여러 가지 힘 / 만유인력)** 연계 시뮬레이션 물리 게임

---

## 🎯 게임 소개
행성들의 질량과 거리에 따라 물체의 운동 궤도가 휘어지는 만유인력($F = G \frac{M}{r^2}$)을 체감하고, 우주 탐사선이 실제로 사용하는 **중력 슬링샷(스윙바이)** 기동을 조작해보는 교육용 웹 게임입니다.

- **발사 각도 및 세기 조절**: 슬라이더 조절 또는 캔버스 직접 드래그/터치로 직관적인 조준
- **궤적 예측**: 발사 초기 진행 방향을 살짝 보여주어 중력 휨 예측 유도
- **10가지 단계별 물리 미션**:
  - Stage 1: 중력과의 첫 만남 (만유인력과 궤도의 휨)
  - Stage 2: 질량과 중력의 크기 (질량 비례 법칙)
  - Stage 3: 중력 슬링샷 (스윙바이 - 180도 U턴 기동)
  - Stage 4: 라그랑주 중력 균형 (힘의 평형과 합력 = 0)
  - Stage 5: 삼체(Three-Body) 중력장 (다체 문제와 합성 벡터)
  - Stage 6: 공전하는 행성 (움직이는 천체와 상대 운동)
  - Stage 7: 반중력 펄서 (척력과 인력의 상호작용)
  - Stage 8: 소행성대와 중력 터널 (장애물 회피 궤도)
  - Stage 9: 2연속 중력 스윙바이 (다중 중력 도움)
  - Stage 10: 은하계 마스터 슬링샷 (보이저 미션 연쇄 스윙바이)

---

## 🚀 실행 방법
웹 브라우저(`Chrome`, `Edge`, `Safari` 등)에서 `index.html` 파일을 열거나 로컬 웹 서버를 실행합니다.
