# FRICTION LAB · 마찰 연구소 탈출

중학생용 마찰 실험 탈출 게임입니다. 10단계에서 손 문지르기, 사포, 기울기, 제동, 장애물 우회, 마찰 차이에 의한 상자 회전을 경험합니다.

## 실행

Node.js가 설치된 환경에서 이 폴더에서 `npm start`를 실행한 후 **http://localhost:5173**을 엽니다. 추가 패키지 설치는 필요 없습니다. Phaser 배포 파일과 MIT 라이선스를 `vendor/`에 포함했습니다.

## 조작

게임판은 브라우저 화면 전체를 채웁니다. 설명·10단계 선택·힘 보기·전체 초기화는 하단의 ☰ 메뉴에서 엽니다. ⛶ 버튼으로 지원 브라우저의 전체 화면 모드에 진입할 수 있습니다.

마찰 범위는 0.001~3.0이며 0.005 간격으로 조절합니다. 거친 표면에서 강한 제동, 아주 매끄러운 표면에서 긴 미끄러짐을 비교할 수 있습니다.

- 바닥을 클릭하거나 터치한 채 여러 번 문지릅니다. `1`은 손, `2`는 사포입니다. 물체를 직접 끌어 이동시키지는 않습니다.
- 방향키 또는 화면 화살표를 누르면 그 방향으로 기울어집니다. 놓으면 수평입니다.
- 태블릿에서는 센서 연결을 누른 후 편한 자세에서 수평을 맞춥니다. 약 35도 기울기에서 최대 입력에 도달합니다. 화면의 가로·세로 방향을 반영합니다.
- 힘 보기는 3초간 중력의 판 평행 성분과 접촉 마찰력을 표시합니다.
- 물체만 초기화하면 표면은 유지됩니다. 전체 초기화와 방 선택은 표면도 초기화합니다.
- 화면 테두리에 충돌벽이 없어서 물체가 밖으로 나갈 수 있습니다. ↺로 다시 가져올 수 있습니다. 단계 내부의 눈에 보이는 벽은 물리 장애물입니다.
- 화면 회전이나 크기 변경 시 물체를 출발 위치로 되돌리며 기존 위치의 바닥 마찰을 보존합니다.

## 태블릿 배포

`index.html`, `style.css`, `src/`, `vendor/`를 정적 호스팅에 올립니다. GitHub Pages와 같은 **HTTPS** 주소에서 센서를 사용하세요. 휴대기기에서 로컬 PC의 HTTP 주소로 접속하면 센서 대신 화면 화살표로 실험할 수 있습니다. 센서 지원과 권한은 기기에 따라 다릅니다.

## 물리 모델

위에서 보는 판 위의 **미끄러지는 공과 상자** 모델입니다. 실제 구의 순수 구름 운동을 재현하지는 않습니다. 아래 방향 중력 자체가 화면 아래쪽으로 작용하는 측면 게임이 아니라, 기울기로 생기는 판 평행 중력 성분이 두 화면 축에 작용합니다.

32×32 타일의 마찰값을 각각 저장합니다. 동적 마찰은 접촉점의 속도 반대 방향으로 작용하고, 정지 상태에서는 임계값 이하의 판 평행 중력 성분을 상쇄합니다. 마찰 충격량은 한 프레임에 속도가 뒤집히지 않도록 제한합니다. 상자는 8개의 접촉점에서 힘을 받고, 각 힘의 작용점으로 인한 토크를 Matter가 적분합니다. 벽 충돌도 Matter로 처리합니다. 속도 의존성과 공기 저항을 포함한 교육용 근사 모델이므로 마찰계수나 실제 SI 속도를 정밀 측정하는 용도로 사용하지 않습니다.

### 실험

모든 단계에서 **물체 전체가 골 안에 들어가고 이동과 회전을 멈춘 채 0.8초 유지**해야 클리어됩니다. 통과하거나 일부만 들어가면 클리어되지 않습니다. 움직임이 다시 생기거나 골을 벗어나면 확인 시간이 초기화됩니다. 골 둘레에 정지 확인 진행률이 표시됩니다. 수치 적분 오차만 허용합니다(선속도 0.001px/물리 프레임 이하, 각속도 0.00001rad/물리 프레임 이하).

| 단계 | 미션 | 난이도 변화 |
|---|---|---|
| 1 | 길만 바꿀 수 있다 | 작업 구간만 편집 가능, 골은 고정 고무 |
| 2 | 멈추지 않는 얼음 | 가운데 고정 얼음을 건너기 |
| 3 | 얼음 위의 골 | 골 바닥도 변경 불가, 반대 기울기로 제동 |
| 4 | 사포만 남았다 | 사포만 사용, 모퉁이와 제동 구간 설계 |
| 5 | 순서가 있는 연구소 | 손만 사용, 두 스위치에 순서대로 정지 |
| 6 | 속도 인증 터널 | 지정 속도로 센서 통과, 과속은 재시도 |
| 7 | 고무 늪을 돌파하라 | 고정 고무를 관성으로 넘어 속도 센서 작동 |
| 8 | 붙잡힌 왼쪽 | 한쪽 고정 고무로 비대칭 회전, 폭 96px 문 |
| 9 | 세로 주차 전용 | 폭 72px 문, 사포 전용 구간, 방향 맞추기 |
| 10 | 연구소 최종 보안 | 두 정지 스위치, 얼음, 폭 60px 문, 세로 주차 |

상자는 108×44px입니다. 마지막 단계를 완료하면 전체 탈출 메시지가 나오며, 1단계부터 다시 도전할 수 있습니다.

파란 빗금은 고정 얼음, 갈색 빗금은 고정 고무입니다. 마찰이 변경되지 않습니다. 노란 구간은 사포만 허용합니다. 번호 스위치는 지정 순서로 전체 물체를 넣고 0.5초 정지하면 작동합니다. 속도 센서는 표시된 범위의 게임 속도(px/물리 프레임)로 통과해야 합니다. 스위치가 모두 작동하기 전에는 골이 회색입니다. 세로 주차는 상자 방향이 표시 방향의 ±0.12rad 이내여야 합니다. ↺는 바닥을 유지하고 장치 상태를 초기화합니다.

## 구조 및 확인

저사양 태블릿을 위해 바닥을 CanvasTexture로 캐시하고 실제로 변경된 타일만 갱신합니다. 문지르는 동안 텍스처 업로드는 초당 최대 20회이고, 정지 중에는 바닥 업로드가 없습니다. 붓 계산은 주변 최대 9개 타일만 검사하며, 글자 객체는 재사용합니다. 표시 프레임은 최대 60회로 제한하고 숨겨진 페이지의 물리를 정지합니다. 고해상도 배율에 맞춰 렌더 버퍼를 추가 확대하지 않습니다.

개발 PC의 동일한 브라우저에서 CPU 4배 지연을 적용한 10단계의 3초 측정: 스크립트 처리 시간 2.143초 → 0.434초(약 80% 감소), 전체 작업 시간 2.342초 → 0.607초. 실기기의 FPS나 배터리 성능을 보장하는 수치는 아닙니다. 실제 Galaxy Tab에서 센서·터치 반응은 확인해야 합니다.

- `src/physics/SurfacePhysics.js`: 타일과 접촉 마찰
- `src/input/TiltController.js`: 키보드·터치 화살표·센서
- `src/main.js`: Phaser 실험판과 미션
- `src/stages.js`: 10단계 구성과 화면 크기별 장애물 배치
- `src/physics/Goal.js`: 전체 포함·정지·유지시간 판정
- `src/systems/StageRules.js`: 순차 스위치·속도 센서·주차 방향 판정
- `scripts/serve.mjs`: 의존성 없는 로컬 정적 서버
- `tests/physics.test.mjs`: 핵심 힘과 토크 검증 (`npm test`)
